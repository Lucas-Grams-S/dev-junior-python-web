# Módulo 5 — Framework web: Django

## 🎯 Objetivos
- Explicar MVC e a variação MVT e o ciclo de vida de uma requisição Django
- Modelar com ORM, migrações, relacionamentos e agregações
- Diagnosticar e corrigir N+1 com `select_related`/`prefetch_related`
- Usar Admin, formulários, autenticação e permissões
- Implementar carrinho e pedido com controle de estoque transacional
