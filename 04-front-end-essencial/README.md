## 🎯 Objetivos
- Escrever HTML semântico e formulários acessíveis
- Montar layouts responsivos com flexbox e grid
- Manipular o DOM e eventos com JavaScript
- Consumir uma API REST com `fetch` e `async`/`await`
- Situar React/Vue/HTMX em uma conversa técnica
