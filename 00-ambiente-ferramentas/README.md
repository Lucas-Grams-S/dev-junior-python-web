# Módulo 0 — Ambiente e ferramentas do dev

> ⏱️ 6 sessões · 9 h · Pré-requisitos: Nenhum.
> 🏷️ Marco no Git: `v0.0-ambiente`

## 🎯 Objetivos
- Navegar e automatizar tarefas no terminal Linux/WSL
- Criar ambientes virtuais e instalar pacotes com `venv`/`pip` e `uv`
- Versionar código com Git e colaborar via GitHub (branch, PR, conflito)
- Usar o debugger e ler mensagens de erro e documentação
- Usar IA como assistente sem terceirizar o aprendizado
